### ⭐⭐ One factor needed no new owner at all

A first draft added a `net_margin()` function. The registry's own integrity test
then reported that `axiom.net_margin` declares `unit: percent` while its formula
no longer showed a ×100 — **the scaling had been hidden inside the function.**

⛔ The right answer was **fewer owners, not a new one**: `margin()` already owns the
division, so the formula became `margin(is.pat, is.revenue) * 100`. **§7r-D's worry
was a fourth site computing a margin; this extraction adds none.**

### The name: `assets_to_equity`

`leverage` already means **debt-to-equity** in `ratios.py` — `cost_of_debt_at`,
`cost_of_equity_at` and `wacc_at` all take it as the Hamada relevering input. The
registry's `financial_leverage` is **assets over equity**.

⛔ A second meaning of the word inside the module that owns the first is the
collision class in a variable name. **`assets_to_equity`** says what it computes
and matches the house convention (`debt_to_revenue`, `net_debt`, `total_debt`).
Finance calls it the equity multiplier; the registry id maps to it.

### Why the asset basis never mattered

```
net_margin × asset_turnover × financial_leverage
  = (PAT/Rev) × (Rev/avgA) × (avgA/E)
  = PAT/E
  = ROE
```

The `avgA` terms **cancel**. The asset basis cannot reach the identity; only the
equity term survives, and the entire pre-A2 residual was `E_end/avg(E)`.

period-end, so either existing value would be false about half the quantity. ⭐ Added
**deliberately, not silently** — and because nothing validates the vocabulary, a
typo here would be silent, which is itself worth recording. The precision lives in
`definition:`, which a reader actually sees.

**After: `point_in_time` 64 · `average` 12 · `mixed` 1.**

`dupont_three_step` becomes **`point_in_time`** — it now equals `axiom.roe`, and R4
fixes ROE as point_in_time. Declaring `average` would contradict the quantity it
reconciles to.

`definition:` for `financial_leverage` rewritten — the old text said *"average
assets over average equity"* and is now false.
